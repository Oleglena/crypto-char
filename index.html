Crypto Chat

Зашифрованный мессенджер через GitHub Gist

Как это работает:
• Все сообщения (текст, фото, аудио, файлы) шифруются AES прямо в браузере
• Ключ — ваша сид-фраза, никуда не отправляется
• Хранятся в вашем GitHub Gist как зашифрованный текст
• Одинаковая сид-фраза у всех = общий чат

Токен: GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new → галочка gist
Gist: gist.github.com → создать → файл chat.txt → сохранить → ID из URL
